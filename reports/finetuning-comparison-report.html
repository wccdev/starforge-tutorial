典型案例对比

以下样本来自验证集真实生成（NeMo RL Console MCP · get_validation_samples）。展示同一类题目在不同配置下的行为差异。

案例 1 · 公司专有设备参数
EUVC201 的灯管分为几层？每层有几个 stage？
选项 A. 5,3   B. 3,5   C. 3,3
单选题 · 需查阅 ORC 设备培训资料
① 未微调 未命中
模型无内部资料访问，对 EUVC201 展开大量通用半导体知识推理，无法定位到培训试卷中的标准答案，输出被截断。
（无有效 \boxed{} 答案）
② 微调无工具 格式改善
GRPO 训练后模型更稳定地使用 \boxed{} 格式，但对机台型号类专有题仍依赖参数记忆，无检索能力时准确率提升有限。
③ 微调 + 工具 1.0 + 检索加成
<search>EUVC201 灯管 stage</search> 检索命中培训答案文档：
【ORC设备培训考试答案.md】L12: EUVC201的灯管分为几层？每层有几个stage?（A）→ 5, 3
依据资料直接给出答案。
\boxed{A}
结论：专有设备参数题，基座几乎无法答对；Agent 微调后学会「先检索、再作答」，从资料库精确命中答案。
案例 2 · 工艺 SOP / 规范条文
开 SRC 无需找人进行 double check，自己 check 就好。
判断题 · A. 对   B. 错
① 未微调 1.0
凭通用安全管理常识推断「应上报复核」，给出 \boxed{B}。答对但无法引用公司 SOP 原文作为依据。
② 微调无工具 ~1.0
单轮微调强化答题格式与推理链，对规范类判断题有提升，但仍不能展示检索轨迹或可审计的资料出处。
③ 微调 + 工具 1.0 + 检索加成
<search>SRC double check</search> 检索命中：
【FAB2 YE Onduty SOP】SRC review，PE check
【MO case summary 试题】SRC owner 通知 double check 时，务必通知对应签核人员…
基于公司内部 SOP 原文判定说法错误。
\boxed{B}
结论：Agent 不仅答对，还能给出可溯源的公司文档依据——更适合生产场景下的合规审计。
案例 3 · 无尘室管理制度
手套、无尘服、电脑、设备、工具等禁止写字乱涂乱画。
判断题 · A. 对   B. 错
① 未微调 1.0
用通用洁净室常识推理：「禁止涂写以防污染」，输出 \boxed{A}。正确，但 reasoning 冗长，无制度条文支撑。
② 微调无工具 1.0
微调后回答更简洁，仍依赖常识；对需要精确引用 FAB 制度的场景帮助有限。
③ 微调 + 工具 1.0 + 检索加成
<search>禁止 写字 手套 无尘服 工具</search> 检索命中 GC FAB2 无尘室管理制度：
➢禁止在无尘服、手套、电脑、机台、键盘、文件袋、工具、墙上等写字、乱涂乱画
直接引用制度原文，输出 \boxed{A}。
结论：常识题三者都能答对；Agent 的优势在于可核验的制度引用，降低幻觉风险。
案例 4 · 基座典型失败模式
DV38 机台的厂商是？   A. LAM   B. JET   C. DNS
单选题 · 验证 step 0 · reward = -0.5
① 未微调 -0.5
模型在 LAM / JET / DNS 之间反复猜测，生成数千 token 推理仍无结论，最终被截断——典型「公司题库 OOD + 无检索」失败。
（未输出 \boxed{}）
② 微调无工具 改善
GRPO 奖励塑形后，模型学会更快收敛到 \boxed{} 格式，减少无效 token；但对纯记忆型机台厂商题，仍无法保证正确。
③ 微调 + 工具 检索命中
同类 WET 设备题（DV38 Medium dispenser 功能）可通过检索试卷资料回答：
【Group 4-DV38试题.md】Medium dispenser 模块用于提供酸液、DIW 及吹干用 N2
Agent 路径将「猜厂商」转化为「查资料 → 作答」。
结论：基座在 OOD 专有题上易陷入无限推理；微调 + 检索是应对公司技术题库的关键组合。

总结

GRPO 微调在公司技术培训 QA 任务上效果显著，Agent 组进一步放大优势。

  • 微调本身有效：单轮 GRPO 将验证准确率从 54.3% 提升至 73.3%（+19 pp），说明奖励塑形能教会模型更好的答题格式与领域推理。
  • 工具 + 微调协同更强：Agent 组达 88.6%，比基座高 34.3 pp，比单轮微调高 15.3 pp——多轮 BM25 检索让模型能回答基座「不可能记住」的专有参数题。
  • 可解释性差异：Agent 回答附带检索片段与文件名行号，便于人工复核；基座依赖常识猜测，专有题易幻觉或截断。
  • 实验设置：Qwen3.5-9B-Base + LoRA · GRPO · 自有 qa_rl 题库 · LLM-as-judge 简答判分 · H100 单卡。
